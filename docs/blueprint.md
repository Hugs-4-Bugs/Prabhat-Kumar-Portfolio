# **App Name**: Prabhat Kumar - Software Alchemist

## Core Features:

- Interactive Home: Dynamic display of Prabhat's profile, experience highlights, and a personalized welcome message with animated elements powered by GSAP and Framer Motion, triggered by user interaction.
- Cutting-Edge Services Showcase: Visually engaging display of Prabhat's services (API Development, Java, Cloud, Trading Solutions, AI/ML, Web Dev, UI/UX, Architecture) with dynamic transitions and interactive elements using GSAP and ScrollTrigger. Generative AI analyzes the effectiveness of project description via A/B testing and suggesting ways to improve it acting as a tool.
- Project Portfolio with Dynamic Filtering: Interactive portfolio page showcasing 15+ projects with live links. Projects will use dynamic filtering based on tech stack (React, Spring Boot, etc.). Implements a 'view more' functionality to handle large number of projects. GSAP and Lenis is used for advanced animations, smooth scrolling, and enhanced user engagement. Project details fetched dynamically from a database for easy updates. Project details can be added or modified through a protected admin route.
- AI-Powered Resume Parser and Display: Allow users to upload a resume and auto-fill the 'contact me' form and to also show up in key area in resume summary. Integrate an AI tool to suggest the applicant which fields are important and should be in there resumes so it should look good when users wants to contact him.
- Contact Form with AI-Enhanced Spam Detection: A contact form to allow visitors to send messages directly. Uses a Generative AI tool to classify any messages as Spam to protect from bots.
- Blog Integration: Integration with a blogging platform for Prabhat to share articles and insights on AI, Trading, and Software Development.
- Social Media Links: Integration with various social media account and portfolio.

## Style Guidelines:

- Primary color: Deep blue (#1E3A8A), evoking trust and technical expertise.
- Background color: Very light gray (#F5F5F5) for the light theme and Dark Gray (#121212) for the dark theme.
- Accent color: Vibrant yellow (#FFD700) to highlight key information and calls to action.
- Body font: 'Inter' sans-serif for a modern, readable, neutral feel.
- Headline font: 'Space Grotesk' sans-serif for a computerized, techy feel.
- Custom icons with a linear style, providing a clean and modern look.
- Clean, modern layout with a focus on readability and user experience. Incorporates dynamic elements that adapt to different screen sizes.
- Subtle animations on scroll and hover, enhancing the user experience without being distracting, implemented using GSAP, Framer Motion, and Anime.js. Floating cursor effects for added interactivity.
